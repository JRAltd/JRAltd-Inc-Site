# JRAltd Inc. Official Website

Source code and assets for [jraltdinc.us](https://jraltdinc.us/), the official website of JRAltd Inc. (Jeremy Allen).

## Overview

The site showcases:
- **Android Apps**: Flip Note
- **Microsoft Outlook Add-in**: Email Sticky Notes (with 30-second sideloading walkthrough and manifest)
- **Gmail Tools**: JRAltd Weather for Gmail (Google Workspace Add-on) and Gmail Weather Companion (Chrome Extension)
- **Windows Tools**: JRAltd Inc Program Updater (WinGet-powered desktop updater)
- **3D Printing**: Maker portfolio and designs on Thingiverse
- **AI Music**: Streaming links on Suno and YouTube Music

## Key Pages

- `index.html`: Main landing page with modern dark theme and responsive layout.
- `email-sticky-notes.html`: Dedicated guide, capabilities, and install instructions for Email Sticky Notes for Outlook.
- `gmail-weather-addon.html`: Dedicated details for JRAltd Weather for Gmail.
- `email-sticky-notes-manifest.xml`: Production manifest for 1-click Outlook add-in sideloading.
- `flipnote-privacy.html`: Privacy policy for Flip Note Android app.
- `gmail-weather-companion-privacy.html`: Privacy policy for Gmail Weather tools.
- `sitemap.xml` & `robots.txt`: Search engine optimization and crawl specifications.
